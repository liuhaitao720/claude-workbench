# v2.2.1 发布说明

SSH Workbench v2.2.1 —— 四项实测修复（重挂栅格 / 推送显示名 / 删任务复活 / 换行错乱）+ cwb-server 0.2.1。

## 1. 修复：重连/恢复远程任务后长路径换行错乱

**现象**：恢复任务或重连认领后，终端里长路径/长行按旧列宽折行，显示错乱。

**根因**：re-attach 只恢复数据流，不重设栅格——服务端 PTY 保留的还是旧会话
列宽，readline 按旧列换行。

**修复**：

- attach / 重启认领后立即补发 `task.resize`（按记忆尺寸）
- 连接转「已连接」时，渲染侧对每个打开的远程任务强制重同步一次栅格
  （PTY 新挂实例必须被告知当前列宽，即使终端尺寸没变）

## 2. 修复：推送文案显示任务 id 而非名称

**现象**：resume 恢复的旧会话、重启认领的任务，推送里显示的是 id。

**根因**：这两种路径此前不传显示名，服务端注册表无名可推。

**修复**：新增 `task.meta` 帧补传「任务名 + 项目名」，推送文案恢复
「任务名（项目名）」。旧版 cwb-server 自动忽略新帧，可先行升级客户端。

## 3. 修复：删除的任务在重连后又显示出来

**现象**：在本程序里删掉的任务，重新连接后又出现在任务列表里。

**根因**：删除只清了本机 tasks.json；VM 上 `~/.claude/projects` 的会话
jsonl 仍在，**连接成功的增量导入**（自动同步 claude CLI 历史会话）把它当成
新会话拉了回来。

**修复**：新增**会话墓碑**（`deleted-sessions.json`，与 tasks.json 同目录）——
删除任务即记录其会话 id，导入一律跳过。删除即不再复活。

## 4. 修复：打开任务终端白屏（无法加载上下文）

2.2.0 之后开发批引入的回归：终端挂载逻辑内嵌 React hooks，触发
Invalid hook call，React 卸载整棵组件树 → 终端区白屏。该缺陷未进入任何
已发布版本；本版已修正并补了回归测试。

## 5. 定向开台体验：任务窗口打开 SSH 终端

**此前**：切目录脚本整行回显在终端里；下方面板却停在用户主目录不跟随。

**现在**：

- **幕布遮罩**：注入 cd + 跟随钩子期间，终端被幕布遮住（同时拦截键盘/
  点击——注入窗口内键入不会再拼进脚本行）
- **成功才揭幕**：OSC 7 回执（cd 成功）后清屏揭幕——露出来直接就是
  项目目录下的干净提示符，脚本回显与登录横幅一并抹去
- **面板直达**：修复「面板竞速回主目录」（挂载定位与项目目录直达两条
  列目录请求竞速、慢响应后到盖掉新目录）——直达是唯一导航源，另加
  陈旧响应守卫兜底；打开时面板直接落在切换后的目录

## cwb-server 0.2.0 → 0.2.1

- 新增 `task.meta` 帧（任务元数据补传——显示名/项目名）
- 服务端日志带时间戳；推送命中记 info 日志（排障用）
- 客户端首连**自动升级**（无需手动操作）；升级会重启 cwb-server，
  远端保活任务随之结束一次（重开即恢复）
