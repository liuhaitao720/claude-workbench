# v2.2.0 发布说明（含 Windows 免安装包）

SSH Workbench v2.2.0 —— 推送补全（完成/停止/失败/退出）+ 手机答复：任务挂在提问上时，人在外面也能用手机作答。

## 1. 推送补全：任何结束或停止都推送

- 新增事件推送：**Stop**（本轮完成）、**StopFailure**（异常结束）、**任务退出**
- **子 agent 停止不推送**（SubagentStop 不订阅，避免刷屏）
- 合并规则：
  - Stop 与随后 10 秒内的退出 → 合成一条「完成并停止」
  - 同任务 Stop 60 秒节流；等待用户输入（awaiting）仍 5 分钟防抖
- 设置 →「消息通知」新增四个事件开关：等待输入 / 完成并停止 / 异常结束 / 任务退出
- 远程任务改由 cwb-server 0.2.0 直接推送（能力协商），客户端不再重复推；
  旧 server 仍由客户端补推

## 2. 手机答复：不用回电脑也能拍板

当 claude 需要你决定（工具权限、AskUserQuestion、计划审批），而桌面已离开
（默认 5 分钟无键入）时：

1. 客户端挂起该 hook（最长 1 小时），桌面显示横幅「已挂起等手机」
2. cwb-server 生成**一次性链接**，经 **Cloudflare 快速隧道**发到手机
   （`https://<随机>.trycloudflare.com/a/<token>`）
3. 手机浏览器打开应答页 → 点选「允许 / 拒绝」或选择问题选项
4. 答案回送 → claude 继续执行 → 桌面横幅消失并提示「已由手机答复」

**手机也能停止任务**：应答页上的「停止任务」可结束当前任务
（远程任务 server 侧终止，本地任务回送停止指令）。

### 桌面快捷操作

- 横幅「打开手机页面」：在电脑上查看应答页（备用）
- 横幅「回电脑处理」：立即取消挂起，回到终端 TUI 自己处理

### 配置（设置 →「消息通知」）

| 项 | 默认 | 说明 |
|---|---|---|
| 手机答复 | 关 | 打开后才会挂起 hook（公网入口须显式开启） |
| 挂起时限 | 15 分钟 | 超时自动回落 TUI |
| 桌面离开阈值 | 5 分钟 | 超过该时长无键盘输入才放行手机答复 |
| 通道状态 | — | 显示隧道状态与当前挂起数 |

## 3. 安全边界

- **控制端口永不暴露**：cwb-server 仍只监听 `127.0.0.1:17717`；cloudflared 出站，
  只把应答页端口映射到公网
- **一次性 token + TTL**：链接过期或作答后立即失效
- **待答内容只在内存**：不落盘、不进日志、不进审计（审计只记元数据）
- 终端屏内容在任何环节都不展示给手机
- 隧道不可用 / 配置关闭 / 桌面在场 / 载荷无法结构化 → **不挂起**，立即回落 TUI
  （超时、桌面取消、断连、任务结束一律释放，绝不卡住任务）

## 4. 兼容与升级

- cwb-server 需 **0.2.0**（首连自动升级；旧 server 不支持手机答复，其余功能正常）
- 应答页需要 VM 侧能找到 `cloudflared`（`CWB_CLOUDFLARED_BIN` / PATH / `~/.cwb/bin/cloudflared`）；
  缺失时设置页显示「未安装隧道程序」，不影响其他功能
- 桌面端与 server 版本能力协商，无需手工配版本
