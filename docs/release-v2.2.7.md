# v2.2.7 发布说明

SSH Workbench v2.2.7 —— Git 工作台：分支右键「查看提交记录」，中间时间线
按分支过滤。cwb-server 保持 0.2.2。

## 1. 按分支查看提交（用户需求 2026-11-24）

**入口**：Git 面板左栏分支行 → 右键 →「**查看提交记录**」（本地/远程分支
均可）。

**行为**：
- 中间时间线切换为该分支的提交：`git log <branch> --graph`（只看该分支可达
  历史，graph 拓扑仍由 git 计算）
- 面板头显示过滤 chip `⑂ 分支名`，点 **×** 回到全分支（`--all`）混排
- 切换后自动选中该分支首条提交——右栏文件修改/diff 立即可见
- 与顶部搜索框叠加生效（先按分支过滤，再按关键词筛）

**实现**：`logArgs(limit, branch?)` 引擎扩展（branch 经 isSafeRef 白名单校验
后进命令行）；IPC `GitLog` 增第三参；renderer `logBranch` 状态驱动重载。

## 2. 验收建议

- 分支右键「查看提交记录」→ 时间线只剩该分支提交，chip 显示分支名
- 远程分支（origin/xxx）同样可查
- 点 chip × → 回到全分支混排
- 切换分支视图后右栏自动显示首条提交的文件清单
