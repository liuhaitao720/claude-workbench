附打开 SSH 终端的注入时序 —— 修复「缓冲区打印 + 需 Ctrl+C」
改前
通道打开→ 立即敲入 cd+PROMPT_COMMAND（撞上 rc 脚本 / MOTD → 行被吞、回显交错 → 卡住）→ 用户 Ctrl+C
改后
通道打开→ 等 shell 就绪（输出静默 400ms / 见到提示符 / 8s 兜底）→ 干净执行 cd + OSC 7 钩子→ 提示符直接可用
附带修复：死会话重开时先清残留缓冲与旧终端画面（不再回放上一场尾巴）；换连接 / 关台时取消未发出的注入。
