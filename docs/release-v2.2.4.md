# v2.2.4 发布说明

SSH Workbench v2.2.4 —— 文件面板压缩（tar.gz）+ 修复 Ctrl+V 重复粘贴与纯 SSH 误弹安装窗。
cwb-server 保持 0.2.2。

## 1. 文件面板：压缩选中项为 tar.gz

**入口**（FinalShell 式双通道）：

- 工具栏「📦 压缩选中」按钮（多选/框选后批量入口，带计数）
- 行**右键菜单**：压缩… / 下载（文件）/ 重命名 / 删除
  （右键行不在选区内时收敛单选该行；在选区内时压缩作用于整个选区）

**确认弹窗**（压缩前必过）：

- 显示目标清单（>5 项折叠计数）与落盘目录
- **输入压缩文件名，带默认值**：单选=`基名.tar.gz`；多选=`archive-YYYYMMDD-HHmm.tar.gz`
- 同名碰撞**预检**——目标已存在时错误就近显示在输入框下方，不覆盖既有文件
- 名称白名单：非空、无 `/`、不以 `-` 开头、非 `.`/`..`、≤200 字符（防路径穿越与
  tar 选项注入；远端命令逐项 POSIX 引号硬化）
- 执行中确认钮禁用（「压缩中…」）；Esc/取消随时退出；成功自动刷新目录

**链路**：`connection.exec`（`cd 目录 && tar -czf 名 -- 条目…`）——纯 SSH 连接
与开发连接同链，**不依赖 cwb-server**。

## 2. 修复：Ctrl+V 重复粘贴

**现象**：右键粘贴正常；Ctrl+V 粘贴内容出现两份。

**根因**：自定义粘贴键处理 `return false` 只阻止 xterm 自身处理，**没有
`preventDefault`**——浏览器对 keydown 的默认动作把**原生 paste 事件**送进
xterm 的隐藏 textarea（xterm 核心再粘贴一次），与显式 `term.paste()` 叠成
双份。Electron 升级后原生粘贴恢复可用才浮现；右键粘贴不经过 keydown，故
一直正常。

**修复**：粘贴键分支同步 `preventDefault()`（必须在异步读剪贴板**之前**——
默认动作不等人），开发终端与 SSH 终端同步。

## 2b. 文件面板选择交互（FinalShell 式，用户指令）

- **行光标=箭头 + 禁文字选中**：Shift 多选不再出现半截文字高亮。连带修复
  v2.0.1「鼠标箭头化」规则的 CSS 合并事故（声明体丢失，选择器被卷进别的
  规则——行布局被殃及成 flex）。
- **多选底色更醒目**：选中行 accent 浸染 + 左缘条（与普通行/hover 高对比）。
- **状态条=名称输入框**（单选）：点击行后显示选中名——可框选**复制名称**；
  编辑+**回车即改名**（Esc 还原）；多选显示计数+样例名。

## 3. 修复：纯 SSH 连接误弹「需要安装 cwb-server」

**现象**：纯 SSH 连接连上后自动弹「推送安装服务端」确认窗。

**根因**：S4 时代的连接健康检查无条件做 cwb-server 探活（SSH 通而 WS 不通 →
安装弹窗）；纯 SSH（v2.1.0 引入）是裸 shell + SFTP 文件面板，**本就不需要
cwb-server**——两代机制互不知晓。

**修复**：`kind=ssh` 的连接跳过 server 健康检查与在场播报。纯 SSH 从此对
目标机器**零 server 依赖**（连接 = ssh2 直连）。

## 4. 验收建议

- 纯 SSH 连一台未装 cwb-server 的机器：连接即通，**不弹安装窗**；终端可用
- 文件面板：选目录 → 右键「压缩…」→ 默认名出现 → 确认 → 列表出现
  `.tar.gz`；再压同名 → 弹窗内提示已存在
