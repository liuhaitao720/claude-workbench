# v2.1.7 发布说明（含 Windows 免安装包）

SSH Workbench v2.1.7 —— 远程文件管理两项优化（界面设计已确认）。

## 1. 传输记录：右上角按钮弹窗（FinalShell 式）

- 文件面板**底部内嵌传输条移除**，改为工具栏右上角常驻 `⇅` 按钮：
  - **角标 = 活动项计数**（数字即信息）；有失败项转红色数字
  - 鼠标悬停 title 显示聚合进度（`3 项 · 45% · 2.1MB/s`）
- 点击弹出**非模态面板**：标题行（传输记录 / 清空已完成 / 收起）＋ 聚合进度条
  ＋ 保存目录行（打开按钮 / 双击打开）＋ 队列列表（进度 / 取消 / 失败重试）
- **发起新传输自动弹出一次**（立即反馈保留）；手动收起后本轮不再自动弹
- Esc / 点击面板外收起，不拦截终端键盘
- 「清空已完成」只修剪完成/失败/取消项，活动项保留

## 2. 双击远程文件 → 弹窗直接编辑（仅 <5MB）

- 在**下方文件面板双击文件**：
  - `< 5MB` → 拉取内容进弹窗编辑器（等宽字体、Tab 插 2 空格、Esc 关闭）
  - `≥ 5MB` → 维持走下载（进传输记录）
  - 二进制文件 → 轻提示「不支持编辑」，不开弹窗
- **Ctrl+S 直接写回远端**（SFTP 直写，即时完成）：
  - 状态栏「已保存 HH:MM」＋ 右下角轻提示「已保存到远端 · 文件名」＋ 文件清单刷新
  - 保存中按钮禁用防连点；失败在状态栏给出原因 + 重试
- 守卫：
  - **脏态关闭确认**：有未保存更改时点 ×/Esc → 「放弃更改 / 继续编辑」
  - **远端冲突守卫**：保存前复核远端 mtime，已被他人改动 → 「覆盖远端 / 重新加载」
  - 取代 v2.0.1「小文本双击本机默认程序打开」（临时文件链路移除）

## 实测修复（同版本追加）

- 传输弹窗被遮挡：弹层改 **portal 挂 body + fixed 定位**（不再被文件面板

- 「打开保存目录」按钮：默认目录（系统下载/SSH Workbench）现在也显示并可打开
  （保存目录改为 main 侧同源解析实际落位）
